# Dars Taymeri — MacBook ish stoli widgeti

Widget [Übersicht](https://tracesof.net/uebersicht/) (bepul) ilovasi orqali ish stolida doim ko‘rinib turadi va har soniyada yangilanadi.

## O‘rnatish

1. Übersicht'ni yuklab oling va o‘rnating: https://tracesof.net/uebersicht/
2. Uni ishga tushiring — menyu satrida (tepada) uning belgisi paydo bo‘ladi.
3. Belgiga bosing → **Open Widgets Folder**.
4. `dars-taymeri.widget` papkasini shu ochilgan papkaga nusxalang.
5. Widget darhol ekranning o‘ng yuqori burchagida chiqadi.

Mac yoqilganda o‘zi ishga tushishi uchun: Übersicht belgisi → **Preferences** → **Launch Übersicht when I login**.

## Sozlash

- **Joyi:** `index.jsx` ichidagi `top` va `right` qiymatlarini o‘zgartiring (masalan, chap tomon uchun `right` o‘rniga `left: 24px;`).
- **Jadval:** `SCHEDULE` ichida har kun uchun `[boshlanish, tugash, sinf, xona, soatlar]`.
- Vaqt har doim Toshkent bo‘yicha (UTC+5) hisoblanadi.
